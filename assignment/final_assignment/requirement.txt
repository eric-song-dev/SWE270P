Demo Presentation

Full Marks
The demo clearly shows a fully working multi-agent system where agents communicate via the Model Context Protocol (MCP). Each agent has a well-defined role, uses tools appropriately, and collaborates in a coordinated manner. The supporting infrastructure (clients, servers, tools) is correctly configured and performs smoothly during the demo. The student(s) explain the agent roles, collaboration pattern, and MCP integration clearly and answer all follow-up questions.
12 pts

Partial Credit
MCP integration and agent communication are demonstrated, but with minor flaws. Roles are mostly clear, and the infrastructure is functional, though some steps required clarification during the demo. The student(s) are able to explain key aspects of the agent roles, collaboration pattern, and MCP integration, and answer most follow-up questions.
9 pts

Partial Credit
The demo includes a basic multi-agent setup, but agent coordination is weak, and MCP usage is not clearly demonstrated or consistently applied. Agent roles are not well defined, and parts of the infrastructure or protocol are incomplete or unstable. The student(s) provide only partial explanations of the system and struggle to answer several follow-up questions.
4 pts

Partial Credit
A partially working system is shown, but key components are missing or non-functional. MCP integration is not meaningfully demonstrated, and agent communication and collaboration within the multi-agent system are unclear. The student(s) are unable to explain the overall system architecture or justify agent behaviors, and they are unable to answer most follow-up questions related to MCP usage or the collaboration logic.
2 pts

No Marks
No demo is conducted, or the demo fails to show any meaningful implementation of a multi-agent system using MCP. Agent roles, collaboration, and protocol usage are either entirely absent or non-functional. The student(s) are unable to explain the system or answer any questions related to the project.
